## Update policy

- Count a contributor only if the merged PR author is not the repository owner and represents an independent contributor.
- Count external PRs by the maintainer only when the target repository is not owned by the maintainer.
- Do not infer or fabricate missing values.
- Keep supporting PR/repository links when values become non-zero.

# OSS Action Plan

## Phase 1 — contributor readiness

- Merge contributor guide and GitHub templates.
- Keep the repository easy to verify with documented commands.
- Open a small backlog of genuine, independently useful issues.

## Phase 2 — external contribution growth

- Prefer issues that can be completed without access to private context.
- Review external PRs quickly and consistently.
- Preserve contributor attribution and verification evidence.

## Phase 3 — application evidence

- Maintain a rolling count of unique external contributors with merged PRs.
- Maintain a separate count of maintainer PRs merged into repositories not owned by the maintainer.
- Record public adoption signals only when independently verifiable.

## Guardrails

No fake accounts, contribution rings, fabricated usage, meaningless PR splitting, or changes that weaken product quality merely to increase activity metrics.
